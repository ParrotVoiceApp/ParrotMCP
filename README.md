# Parrot MCP

Parrot MCP covers connecting AI agents to Parrot calling tools through the Model Context Protocol (MCP).

## Scope

- Agent connections and the calling experience.
- Agent skills and integration guidance.
- Availability in agent marketplaces.

## Current status

This repository provides public issue tracking and product planning. Product source code is not currently published here.
